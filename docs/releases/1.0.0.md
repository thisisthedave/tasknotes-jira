# TaskNotes for Jira 1.0.0

## Added

- Released TaskNotes for Jira as an Obsidian companion plugin for importing Jira issues as TaskNotes tasks.
- Added the **Import Jira issue as task** command with Jira-key normalization and validation.
- Added runtime adapters for the Jira Issue plugin and TaskNotes, including compatibility checks and actionable notices when either dependency is missing or incompatible.
- Added Jira issue retrieval through Jira Issue and task creation through TaskNotes' public runtime API so TaskNotes continues to apply its task defaults, templates, filename handling, cache updates, and events.
- Added configurable mappings from Jira JSON paths, templates, fixed values, and disabled sources to built-in TaskNotes fields.
- Added multi-source merging and deduplication for list-valued fields, Jira-to-TaskNotes value remapping for statuses, priorities, and contexts, and mappings for TaskNotes user-defined fields.
- Added conversion of Jira rich-text documents to Markdown-compatible task details.
- Added a canonical `JIRA:PROJ-1234` backlink to imported task details while preserving mapped content and preventing duplicate backlinks.
- Added an option to use the active note as the project when the Jira mapping does not provide one.
- Added versioned, plugin-owned mapping settings with defaults, normalization, and persistence.
- Added a settings preview that fetches a sample Jira issue, shows resolved or missing mapping values, and keeps the sample key and payload in memory only.
- Added a collapsed, vertically resizable raw Jira JSON viewer with safe text rendering, display truncation, and copying of the complete payload.
- Added unit coverage for dependency adapters, imports, field mapping, settings, and preview behavior.
- Added production and test-vault build helpers, release automation, linting, and plugin metadata for the `tasknotes-jira` package.
- Added installation, configuration, usage, privacy, compatibility, troubleshooting, and development documentation with screenshots of the import and mapping workflows.

## Changed

- Moved the Jira import feature from the TaskNotes fork into a separately owned companion plugin.
- Replaced the legacy feature's access to TaskNotes internals with supported dependency boundaries and TaskNotes' public `createTask` API.
- Delegated Jira authentication and network access entirely to Jira Issue; the companion plugin does not read or store Jira credentials.
